# 学生端章节练习界面改版（2026-09-21）

## 页面结构
- 章节选择、教材和收藏入口位于顶部；移除独立的导师步骤。
- 章节首页左右分别展示自由练习设置卡和可滚动的闯关路线。
- 自由练习选择难度，默认混合题型，可指定类型；生成题目时轮换当前章节小节。
- 闯关暂按实际目录小节分关，每轮 5 题、混合题型、中等难度，全部可进入。以上是前端原型参数，不是最终难度/通关方案。
- 两种模式共用答题界面；支持跳过、返回已做题目、结果回顾、再次挑战。
- 题下导师支持提示、检查思路、自由提问；传入题干、选项、当前答案和判题反馈。

## 状态和边界
- 按姓名和班级保存到浏览器 localStorage，不代表身份认证或跨设备同步。
- 分章节、模式、关卡保留当前一轮的题目、答案、首次结果、求助标记、导师对话和输入草稿。
- 开始新一轮前确认替换当前轮，暂不保存多轮历史。
- 新题成功生成后才替换当前题；失败时保留现场并显示可理解的提示。
- 设置修改只影响下一道新题，浏览已经生成的题目不会改变它。
- 首次独立答对与最终订正结果分开；跳过显示为待复习，不计为答错。
- 未设置通关阈值或强制解锁；五题结束仅代表一轮结束。
- 判题/导师 API 返回演示 fallback 时，新界面显示服务错误，不把模拟结果保存成真实评阅。
- 后端重启后，已保存在浏览器的题目可能无法继续判题，需要换题；旧记录仍可阅读。
- 教材原始标题继续使用现有翻译映射，未覆盖的教材标题保留原文。
